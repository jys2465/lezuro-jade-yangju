# 레저로 파크골프 · 제이드 양주점 — 방향 기록장 (v2)

회원이 코스(18홀)마다 자기 방향 기록을 남기고, 공개한 다른 회원 기록을 참고·비교하는 휴대폰 웹앱입니다.

- 화면: GitHub Pages
- 서버: 구글 앱스크립트
- 저장소: 구글 시트

설치는 **A(시트) → B(설정 파일) → C(GitHub) → D(첫 로그인) → E(결제 설정) → F(좌석 수 정하기)** 순서로 한 번만 하면 됩니다. (약 40분) 지점을 늘릴 때는 **G(지점 추가하기)**만 하면 됩니다.

v1을 이미 쓰고 있다면 맨 아래 **"v1에서 옮겨 오기"**를 먼저 보세요.

## 0. 폴더 구성

| 경로 | 설명 |
|---|---|
| `index.html`, `manifest.json`, `sw.js`, `.nojekyll` | 앱 본체 (GitHub에 올림) |
| `css/`, `js/`, `assets/`, `icons/`, `vendor/` | 앱 본체 (GitHub에 올림, 폴더째) |
| `js/config.js` | ★ 서버 주소와 지점 코드를 넣는 파일 |
| `apps-script/Code.gs`, `apps-script/appsscript.json` | 구글 시트에 붙여 넣는 서버 코드 |
| `tools/loadtest.js` | 부하 시험(좌석 수 정하기). 내 컴퓨터에서 실행 |
| `tools/app.src.css`, `tools/build-css.py` | 화면 디자인 원본(개발용) |
| `tests/` | 개발용 자동 시험 (GitHub에 안 올려도 됨) |

앱 파일에는 비밀번호나 열쇠가 들어 있지 않습니다. 그래서 저장소를 공개(Public)로 둬도 안전합니다.

## A. 구글 시트와 서버 준비

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. 이름은 예를 들어 `레저로 파크골프 양주점`.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. `Code.gs` 안의 내용을 모두 지우고, `apps-script/Code.gs` 전체를 붙여 넣은 뒤 저장합니다.
   - 위쪽의 `ADMIN_NICK = '관리자'`가 관리자(개발자) 닉네임입니다. 바꾸고 싶으면 여기서 고칩니다.
   - 위쪽의 `BRANCH = 'yangju'`가 **지점 코드**입니다. (아래 "지점 코드" 참고)
4. 시간대를 맞춥니다.
   1. ⚙ **프로젝트 설정**에서 "appsscript.json 매니페스트 파일 표시"를 체크합니다.
   2. `appsscript.json` 내용을 `apps-script/appsscript.json`으로 바꿉니다. 시간대가 `Asia/Seoul`이어야 시작일·종료일이 하루씩 어긋나지 않습니다.
   3. 시트의 **파일 → 설정 → 시간대**도 서울로 맞춥니다.
5. 함수 목록에서 **`setup`**을 고르고 ▶ **실행**을 누릅니다.
   - 권한 확인 창에서 **고급 → (안전하지 않음)으로 이동 → 허용**을 누릅니다. 내가 만든 스크립트라 정상입니다.
   - 끝나면 **관리자 닉네임과 처음 비밀번호**가 나옵니다. 실행 로그에도 나옵니다. **꼭 적어 두세요.** 다시 볼 수 없습니다.
   - 시트 8개(회원, 로그인기록, 코스, 기록, 공개설정, 결제, 설정, 이력)와 매일 새벽 자동 정리·백업 예약이 만들어집니다.
6. **배포 → 새 배포 → 유형: 웹 앱**을 고르고 아래처럼 설정한 뒤 **배포**를 누릅니다.
   - 실행: **나**
   - 액세스: **모든 사용자**
7. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 서버 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 하세요. 주소가 그대로 유지됩니다.

## B. 설정 파일 고치기

`js/config.js`를 열고, 지점마다 복사한 웹 앱 URL을 넣습니다. 앞의 영문(`yangju`, `mansong`)이 **지점 코드**이고, 그 지점 `Code.gs`의 `BRANCH`와 같아야 합니다.

```js
window.LZ_CONFIG = {
  DEFAULT: 'yangju',
  BRANCHES: {
    yangju:  { name: '제이드 양주점', API: 'https://script.google.com/macros/s/……/exec' },
    mansong: { name: '양주만송점',   API: 'https://script.google.com/macros/s/……/exec' }
  }
};
```

- 아직 서버를 만들지 않은 지점은 `API`를 `YOUR_…` 그대로 두면 됩니다. 그 지점 주소로 열면 "아직 준비 중이에요"가 나옵니다.
- `DEFAULT`는 주소에 `?s=`가 없을 때 여는 지점입니다. 처음부터 쓰던 양주점이라, 기존 회원은 하던 대로 쓰면 됩니다.
- 예전 모양(`API`, `BRANCH` 한 줄씩)도 그대로 동작합니다. 지점을 추가하려면 위 모양으로 바꿔 주세요.

### 지점 코드와 지점 주소

- 화면(GitHub 주소)은 하나이고, **서버와 구글 시트는 지점마다 따로**입니다. 회원·기록·결제·좌석·신뢰도가 모두 지점별로 나뉩니다.
- 지점 주소는 끝에 `?s=지점코드`를 붙입니다. 예: `https://아이디.github.io/저장소/?s=mansong`
  - 운영자가 계정을 만들 때 나오는 **초대 안내문에 자동으로 들어갑니다**(`?s=mansong&u=닉네임`).
  - 회원이 초대 링크로 한 번 들어오면 폰이 그 지점을 기억합니다. 홈 화면 아이콘으로 열어도 그 지점입니다.
- **회원과 운영자는 지점을 고를 수 없습니다.** 로그인 화면과 설정에 지점 바꾸기가 없습니다. 계정은 그 지점 서버에만 있어서, 다른 지점 주소를 직접 쳐서 들어가도 로그인되지 않습니다.
- **관리자만** 설정 → "지점 (관리자만)" → **지점 바꾸기**로 지점을 오갈 수 있습니다. 지점마다 관리자 계정이 따로라서, 처음 가는 지점에서는 그 지점 관리자 비밀번호로 로그인합니다.
- 앱은 모든 요청에 지점 코드를 함께 보냅니다. 서버의 지점 코드와 다르면 **"이 앱 주소와 서버의 지점이 달라요"**라고 거절해서, 다른 지점 서버에 잘못 연결되는 것을 막습니다.
- 지점 코드는 **한 번 정하면 바꾸지 마세요.** 바꾸면 그 지점 회원이 모두 다시 로그인해야 합니다.

## C. GitHub에 올리기

1. GitHub에서 **New repository**를 누르고, 이름(예: `lezuro-jade`)을 정해 **Public**으로 만듭니다.
2. **Add file → Upload files**에 압축을 푼 폴더 **안의 내용 전부**를 끌어다 놓습니다. 파일과 폴더를 함께 놓으면 됩니다.
   - PC의 크롬이나 엣지에서 해야 폴더째 올라갑니다.
   - 저장소 맨 위에 `index.html`과 `css`, `js`, `assets`, `icons`, `vendor` 폴더가 보여야 합니다.
3. **Settings → Pages**에서 Branch를 `main` / `(root)`로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/`가 열리면 끝입니다.

> 앱을 고쳐 다시 올릴 때는 `sw.js` 맨 위의 `VERSION` 숫자를 하나 올리세요. 회원 폰에 "새 버전이 있어요"가 뜹니다.

## D. 첫 로그인과 계정 만들기

1. 앱 주소를 열고, A-5에서 받은 관리자 닉네임과 처음 비밀번호로 로그인합니다. 바로 나만의 4자리로 바꾸게 됩니다.
2. 아래 메뉴 **회원**에서 닉네임과 종류(체험, 월간, 연간, 운영자)를 고르고 **계정 만들기**를 누릅니다.
   - 처음 비밀번호는 자동으로 만들어지고, 이 화면에서만 보입니다.
3. **카카오톡·문자로 보내기**를 누르면 안내문이 그대로 전달됩니다. 안내문에는 닉네임이 미리 들어간 개인 링크가 있습니다.
4. 회원은 링크를 열고 처음 비밀번호를 누른 뒤, 나만의 비밀번호로 바꿉니다.

## E. 결제 설정 (관리자만)

**설정 → 요금 · QR · 계좌 · 좌석 · 매장 · 로고**에서 바꿉니다. 운영자에게는 이 메뉴가 보이지 않습니다.

| 항목 | 처음 값 |
|---|---|
| 월간회원 (30일) | 1,000원 |
| 연간회원 (365일) | 9,000원 |
| 계좌이체 | 카카오뱅크 3333-05-8835107, 예금주 표시 `주*수` |
| 카카오페이 QR | 받은 QR(금액 없음) 주소가 들어 있음 |

### 카카오페이 QR 바꾸는 법

1. 카카오페이 앱 → **송금** → **QR로 송금받기**(또는 내 QR)에서 QR을 만듭니다. 원하면 금액을 넣어 월간·연간용을 따로 만듭니다.
2. QR 화면을 **캡처**합니다.
3. 관리자 설정의 **QR 사진에서 읽기**를 눌러 캡처를 고르면, 주소(`https://qr.kakaopay.com/…`)를 자동으로 읽어 칸에 넣습니다.
4. **열어서 시험하기**로 송금 화면이 열리는지 확인하고 **설정 저장**을 누릅니다.

### 결제 흐름 (닉네임 송금 → 관리자 확인)

1. 회원이 결제 화면에서 월간·연간을 고릅니다. 시작일~종료일이 미리 보입니다.
2. 카카오페이(버튼·QR) 또는 계좌이체로 보냅니다. 화면에 **송금 메시지(또는 받는 분 통장 표시)에 닉네임을 적어 달라**는 안내와 [닉네임 복사] 버튼이 있습니다.
3. 회원이 **송금했어요**를 누르면 "입금 확인 중"이 됩니다.
4. 관리자는 **설정 → 결제 확인 · 환불**에서 카카오페이 내역이나 통장의 이름·금액을 보고 **승인**합니다. 승인하는 순간 이용이 시작됩니다.

기간 규칙은 이렇습니다.

- **체험 중에 결제**하면 승인한 날부터 바로 시작합니다.
- **월간·연간 회원**은 종료 14일 전부터 다시 결제할 수 있고, 종료일 **다음 날부터 이어 붙입니다.**
- **기간이 끝난 뒤** 결제하면 승인한 날부터 시작합니다.

> 개인 계좌·개인 카카오페이로는 입금을 자동으로 확인할 수 없어서 관리자 확인 방식입니다. 예금주 실명 일부(`주*수`)가 송금 화면에 보이는 것은 은행·카카오 정책이라 막을 수 없습니다.

### 환불 규정

- 기본은 기간 끝까지 이용합니다.
- 결제 후 **7일 이내**이고 기록을 쓰지 않았으면 **전액** 환불합니다.
- 그 밖에는 **남은 날짜만큼 나눠서** 환불합니다(100원 미만 버림). 예: 연간 9,000원, 100일 사용 → 6,500원.
- 결제 확인 화면의 **환불 계산하기**가 금액을 계산해 줍니다. 처리하면 그 회원의 기간이 어제로 끝나고, 돈은 직접 돌려보냅니다.

## F. 동시 사용 좌석 정하기 (부하 시험)

구글 앱스크립트는 한 계정이 동시에 처리할 수 있는 양에 한도가 있습니다. 그래서 동시에 쓰는 사람이 좌석 수를 넘으면 **대기 화면("내 앞에 N명")**을 보여 주고, 자리가 나면 자동으로 들어가게 했습니다.

- **10분** 동안 화면을 전혀 만지지 않으면 좌석을 비웁니다. 화면을 쓰는 동안에는 자동으로 유지됩니다.
- 운영자·관리자는 기다리지 않습니다.
- 처음 값은 40석이고, 0은 제한 없음입니다.

좌석 수는 실제 서버로 재서 정하는 것이 가장 정확합니다.

1. 컴퓨터에 [Node.js](https://nodejs.org) 18 이상을 설치합니다.
2. 회원이 거의 없는 시간(예: 새벽)에 압축을 푼 폴더에서 실행합니다.
   ```
   node tools/loadtest.js "https://script.google.com/macros/s/……/exec" 관리자비밀번호
   ```
3. 시험용 체험회원 80명(lt01~lt80)을 만들어 동시 10 → 20 → 40 → 80명으로 요청을 보낸 뒤 표를 보여 줍니다. 끝나면 시험용 회원과 기록을 모두 지웁니다.
4. **"느린 쪽 5%가 3초 이하이고 오류가 없는" 가장 큰 인원의 70%**를 추천 좌석 수로 알려 줍니다.
5. 관리자 설정에서 좌석 수를 바꾸거나, 끝에 `--apply`를 붙여 다시 실행하면 자동으로 저장됩니다.

> 회원이 화면을 "보는 동안"은 서버에 요청이 거의 없어서, 실제로는 좌석 수보다 훨씬 많은 사람이 앱을 켜 두어도 괜찮습니다.

## G. 지점 추가하기 (예: 양주만송점)

양주점과 같은 방법으로 **새 구글 시트와 서버**를 하나 더 만듭니다. 화면(GitHub)은 그대로 같이 씁니다. (약 15분)

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. 이름 예: `레저로 파크골프 양주만송점`.
2. **확장 프로그램 → Apps Script**에 `Code.gs` 전체를 붙여 넣고, 맨 위 두 줄만 바꿉니다.
   ```js
   var BRANCH = 'mansong';
   var STORE_DEFAULT = '양주만송점';
   ```
3. A단계 4~7과 똑같이 합니다: 시간대 맞추기 → `setup` 실행(만송점 **관리자 처음 비밀번호**가 나옴) → 웹 앱으로 배포 → URL 복사.
4. `js/config.js`의 `mansong` 줄 `API`에 그 URL을 넣고 GitHub에 다시 올립니다. `sw.js`의 `VERSION`도 올려 주세요.
5. 관리자 폰에서 설정 → **지점 바꾸기 → 양주만송점**을 누르거나, `…/?s=mansong` 주소를 엽니다. 그다음 만송점 관리자로 로그인해 비밀번호를 바꿉니다.
6. 만송점 운영자 계정을 만들어 초대 안내문을 보냅니다. 그 운영자가 만송점 회원(체험)을 만들면 됩니다.
7. 결제 설정(E)과 좌석 수(F)도 만송점에서 따로 정합니다. 부하 시험은 끝에 지점 코드를 붙입니다:
   `node tools/loadtest.js "<만송점 웹 앱 URL>" <만송점 관리자 비밀번호> mansong`

### 다른 방법: 기존 지점 시트를 "사본 만들기"로 복사해서 만들기

코스 목록(이름·파·거리)을 그대로 가져가고 싶을 때 씁니다. 관리자는 원래 지점과 **같은 닉네임·같은 비밀번호**로 들어갑니다.

1. 기존 지점 구글 시트에서 **파일 → 사본 만들기**를 합니다.
2. **원래 지점** Apps Script → ⚙ 프로젝트 설정 → **스크립트 속성**의 `PEPPER` 값을 복사합니다. 이 값은 사본으로 복사되지 않습니다.
3. **사본** Apps Script → ⚙ 프로젝트 설정 → **스크립트 속성 추가**에서 속성은 `PEPPER`, 값은 2에서 복사한 값으로 저장합니다.
4. 사본의 `Code.gs` 맨 위를 `BRANCH = 'mansong'`, `STORE_DEFAULT = '양주만송점'`으로 바꾸고 저장합니다.
5. 함수 목록에서 **`makeNewBranchFromCopy`**를 골라 ▶ 실행합니다. 하는 일은 이렇습니다.
   - **남김:** 관리자 계정, 코스 목록, 요금·QR·계좌·좌석·로고 설정
   - **지움:** 다른 회원, 기록, 결제, 로그인 기록, 이력, 신뢰도, 원래 지점 백업 시트, 등록이 끝나지 않은 코스
   - **바꿈:** 지점 코드·매장 이름
   - 2~4를 안 했으면 아무것도 바꾸지 않고 무엇을 먼저 해야 하는지 알려 줍니다.
6. **배포 → 새 배포(웹 앱)**, 이미 배포했다면 **배포 관리 → ✏️ → 새 버전**을 합니다. 그 URL을 `config.js`의 그 지점 `API`에 넣습니다.

가져온 코스에는 "처음 등록한 분: ○○님 (제이드 양주점)"처럼 원래 지점이 표시됩니다. **수정은 그 지점 운영자·관리자만** 할 수 있습니다. 새 지점에 같은 닉네임 회원이 생겨도 등록자로 인정하지 않습니다. 고칠 수 없는 회원에게는 "코스 정보를 고쳐야 하면 운영자에게 수정을 요청해 주세요"라고 안내합니다.

> 지점마다 서버가 따로라서, 지점이 늘어도 한 지점의 동시 접속 한도를 나눠 쓰지 않습니다. 같은 구글 계정으로 여러 지점 서버를 만들어도 되지만, 지점이 많아지면 지점마다 다른 구글 계정(예: 매장 계정)으로 만드는 것이 한도에 더 여유롭습니다.

## 코스

- 모두 **18홀**입니다. 전반은 1홀~9홀, 후반은 1홀 (10홀)~9홀 (18홀)로 표시합니다.
- **등록은 두 단계**입니다.
  1. 이름과 **전반 9홀**(파·거리, 원하면 홀마다 내 기록)을 넣고 **전반 저장하고 후반으로**를 누릅니다.
  2. "전반 9홀 저장이 완료되었어요. 후반 9홀 등록으로 갈게요." 다음에 **후반 9홀**을 넣고 **등록하기**를 누릅니다.
  - 후반까지 마치기 전에는 **등록한 본인에게만** 보이고, 코스 목록에 "후반 9홀 입력 필요"로 표시됩니다.
- **이름은 한 칸에 띄어쓰기 없이** 스크린에 나오는 그대로 씁니다.
  - 끝의 **AB, CD, BC, EF** 같은 영문 조합이 다르면 다른 코스입니다. AB·CD가 있어도 BC는 새 코스로 등록됩니다.
  - 같은 이름은 등록할 수 없고, "그 코스에 내 기록을 넣으세요"라고 안내합니다.
  - 기존 이름을 줄였거나 한 글자 다르게 쓰면 고친 이름을 제안합니다. 예: `목행충주호파크골프AB`가 있을 때 `목행충주CD` → **"목행충주호파크골프CD"로 등록할까요?**
  - 숫자만 다른 이름(1구장·2구장)은 다른 코스로 봅니다.
  - 한글로 끝나는 비슷한 이름은 "같은 구장의 다른 조합이 맞나요?"라고 한 번 묻습니다.

## 신뢰도

다른 회원이 **내 기록을 가져다 쓰면** 내 신뢰도가 올라갑니다.

- 가져오기(빈 홀만 채우기, 모두 덮어쓰기, 홀 하나만 가져오기)를 하면 그 기록을 쓴 회원에게 **1점**이 올라갑니다.
- **한 회원이 한 코스에서는 몇 번을 가져가도 1점**입니다. 다시 가져가면 날짜만 가장 최근으로 바뀝니다. 다른 코스에서 가져가면 따로 1점입니다.
- 가져온 직후 **되돌리기**를 누르면 방금 생긴 1점은 빠집니다(30분 안). 실수로 누른 것까지 세지 않기 위해서입니다.
- 코스 목록과 설정 위쪽의 **"내 기록 신뢰도 N점"**을 누르면 **언제(가장 최근), 누가, 어느 코스**를 가져갔는지 최근 순으로 보입니다.
  - 회원은 자기 목록만 볼 수 있습니다.
  - 운영자·관리자는 회원 관리 → 관리 → **신뢰도 보기**로 모든 회원의 목록을 볼 수 있습니다.
- 코스 페이지의 **참고할 회원**은 신뢰도 높은 순으로 나오고, 처음에는 신뢰도가 가장 높은 회원이 골라져 있습니다. 같은 점수면 기록한 홀이 많은 순입니다. 회원 이름 옆에 **"신뢰도 N점"**이 보입니다.
- 기간이 끝난 회원은 가져오기를 할 수 없어서 점수도 올라가지 않습니다. 코스나 회원을 지우면 관련 점수도 함께 정리됩니다.
- 구글 시트의 **신뢰도** 탭에 쌓입니다(가져다 쓴 기록 주인, 가져간 회원, 코스, 처음, 최근). 예전 시트에 이 탭이 없으면 처음 쓸 때 저절로 만들어집니다.

## 코스 페이지

- **화면 꺼짐 방지**: 코스 표·홀 편집·비교 분석을 보는 동안에는 휴대폰 화면이 꺼지지 않습니다. 다른 화면으로 가면 원래대로 돌아옵니다.
  - 전원 버튼, 전화, 다른 앱으로 가면 꺼질 수 있습니다. 돌아오면 다시 켜집니다.
- **내 기록만 보기**: 체크하면 다른 회원 줄을 숨깁니다. 폰이 기억합니다.
- **○○님 기록 가져오기**(위쪽):
  - **빈 홀만 채우기**: 내가 아직 기록하지 않은 홀만 채웁니다.
  - **모두 덮어쓰기**: 그 회원이 기록한 홀은 모두 그 기록으로 바꿉니다.
  - 가져온 뒤 **되돌리기**로 돌아갈 수 있습니다.
- **비교 분석**: 고른 회원과 홀별로 비교합니다.
  - 위쪽에 같은 홀·다른 홀·한쪽만 기록한 홀 수를 보여 줍니다.
  - 같은 기준이면 "○○님이 좌측으로 2칸 더", "타격감 1 더 셈(+5M)"처럼 차이를 보여 줍니다.
  - 기준이 다르면 직접 비교하기 어렵다고 알려 줍니다.
  - 홀마다 **이 홀 ○○님 기록으로**, **내 기록 고치기** 버튼이 있습니다.

## 홀 기록

- **기준**을 하나 고릅니다: 최초화면, 홀컵, 내가 정한 곳(이름 직접 입력).
- **방향(좌측/우측)과 칸 수**를 정합니다. 0칸이면 "그대로"입니다.
- **타격감**
  - 17 = 50M이고, 1마다 5M씩 달라집니다. "17(50M) 정도"로 표시합니다.
  - **처음부터 17이 채워져 있고**, 손대지 않으면 17로 저장됩니다.
  - +/− 버튼이나 숫자 직접 입력(8~40)으로 바꿉니다.
- **참고사항**: 20자까지 씁니다.
- **자동 저장**: 고치고 1.5초 뒤 저장합니다.
  - 저장 전에 나가려 하면 "저장하고 나가기 / 저장하지 않고 나가기 / 계속 고치기"를 묻습니다.
  - 인터넷이 끊기면 폰에 보관했다가 다시 연결되거나 앱을 다시 열면 저장합니다.
- **코스 등록 중에 나갈 때**: "임시 저장하고 나가기 / 지우고 나가기 / 계속 작성하기"를 묻습니다.

## 화면

- **밝게 / 어둡게**: 모든 화면 맨 위의 **해·달 단추**로 바로 바꿉니다.
  - 설정의 "화면 모드"에서 밝게 / 어둡게 / 자동(휴대폰 다크 모드 따라감)을 고를 수도 있습니다.
  - 어두운 화면에서는 로고를 작은 흰 바탕에 올려 3색 막대가 모두 보이게 했습니다.
- **글씨 크기**: 보통 / 크게 / 아주 크게.
- **로그인**: 폰마다 마지막 닉네임을 기억해서 비밀번호만 누르면 됩니다. 비밀번호를 5번 틀리면 10분 동안 쉽니다.

## 홈 화면에 추가 (앱처럼 쓰기)

- **안드로이드(크롬)**: 안내 화면의 **홈 화면에 추가** 버튼 한 번이면 됩니다. 버튼이 없으면 ⋮ → 홈 화면에 추가를 누릅니다.
- **삼성 인터넷**: ≡ → 현재 페이지 추가 → 홈 화면을 누릅니다.
- **아이폰(Safari만 가능)**: 공유 버튼 → 홈 화면에 추가 → 추가를 누릅니다. 홈 화면 아이콘으로 처음 열 때는 비밀번호를 한 번 더 눌러야 할 수 있습니다.
- **카카오톡에서 링크를 연 경우**: 앱이 "기본 브라우저로 열기"를 안내합니다.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| "서버 주소가 아직 없어요" | B단계 `js/config.js` 확인 |
| "설정 파일(js/config.js)을 읽지 못했어요" / 모든 지점이 안 열림 | `config.js`에서 지점 줄 끝 **쉼표(,)** 빠짐이나 따옴표 짝 확인. 한 줄만 틀려도 파일 전체를 못 읽어요 |
| "이 앱 주소와 서버의 지점이 달라요" | `js/config.js`의 지점 코드(`yangju`, `mansong`)와 그 지점 시트 **설정** 탭의 `branch` 값을 같게 맞춤. 두 지점의 API 주소가 서로 바뀌어 들어가지 않았는지도 확인 |
| "○○은(는) 아직 준비 중이에요" | 그 지점의 `API`가 아직 `YOUR_…`. G단계로 서버를 만들고 주소를 넣음 |
| 만송점 회원이 양주점 로그인 화면을 봄 | 초대 링크(`?s=mansong&u=…`)로 한 번 다시 열어 달라고 안내 |
| "서버 응답을 읽을 수 없어요" | 배포 액세스가 "모든 사용자"인지, URL이 `/exec`로 끝나는지 확인 |
| 불러오는 중에서 멈춤 | 6초 뒤 빠진 파일 목록이 나옵니다. `css`, `js`, `assets`, `icons`, `vendor` 폴더가 올라갔는지 확인 |
| 날짜가 하루 어긋남 | A-4 시간대 확인 |
| 대기 화면이 자주 뜸 | F단계 부하 시험으로 좌석 수를 다시 정함 |
| 관리자가 비밀번호를 잊음 | Apps Script에서 `devResetAdminPin` 실행 → 관리자 비밀번호를 새로 만들어 줌 |
| 데이터를 되돌리고 싶음 | 매일 새벽 회원·코스·기록·결제 시트의 `bkYYMMDD_…` 숨김 백업이 생깁니다(7일 보관). 시트 메뉴 **보기 → 숨겨진 시트**에서 찾을 수 있어요 |

## v1에서 옮겨 오기

1. 기존 시트의 Apps Script에 새 `Code.gs`를 붙여 넣고 **`setup`을 한 번 실행**합니다. 이렇게 옮겨집니다.
   - 고정회원 → **가입한 날부터 365일 연간회원**
     - 가입한 지 1년이 넘은 고정회원은 옮기자마자 기간이 끝난 상태가 됩니다. `setup` 결과에 이름이 나오니, 필요하면 회원 관리에서 **기간 365일 늘리기**를 눌러 주세요.
   - 기간회원 → **월간회원**(기간 그대로)
   - 기존 코스 → 등록 완료 코스
   - 이전 운영자 → 운영자로 유지
   - `ADMIN_NICK`(처음 값 `관리자`) 계정이 없으면 새로 만들고 비밀번호를 알려 줍니다.
2. **배포 → 배포 관리 → ✏️ → 새 버전**으로 다시 배포합니다(주소 유지).
3. GitHub의 파일을 모두 새 파일로 바꿉니다. `vendor` 폴더가 새로 생겼고, `js/config.js`에는 API 주소를 다시 넣어야 합니다.
4. 회원 폰은 다음에 열 때 새 버전으로 바뀝니다. 로그인은 그대로 유지됩니다.

## 보안 메모

- 비밀번호는 소금과 후추를 더해 암호화한 값만 저장합니다. 후추는 시트가 아닌 스크립트 속성에 보관합니다.
