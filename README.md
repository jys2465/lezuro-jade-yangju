# 레저로 파크골프 · 제이드 양주점 — 방향 기록장

회원이 코스(18홀)마다 자기 방향 기록을 남기고, 공개한 다른 회원 기록을 참고하는 휴대폰 웹앱입니다.

- 화면: GitHub Pages
- 서버: 구글 앱스크립트
- 저장소: 구글 시트

설치는 **A(시트) → B(설정 파일) → C(GitHub) → D(첫 로그인)** 순서로 한 번만 하면 됩니다. (약 30분)

---

## 0. 폴더 구성

| 경로 | 설명 |
|---|---|
| `index.html`, `manifest.json`, `sw.js`, `.nojekyll` | 앱 본체 (GitHub에 올림) |
| `css/`, `js/`, `assets/`, `icons/` | 앱 본체 (GitHub에 올림, 폴더째) |
| `js/config.js` | ★ 서버 주소 한 줄만 고치는 파일 |
| `apps-script/Code.gs`, `apps-script/appsscript.json` | 구글 시트에 붙여 넣는 서버 코드 |
| `tests/` | 개발용 자동 시험 (GitHub에 안 올려도 됨) |

앱 파일에는 비밀번호나 열쇠가 들어 있지 않습니다. 그래서 저장소를 공개(Public)로 둬도 안전합니다.

---

## A. 구글 시트와 서버 준비

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. 이름은 예를 들어 `레저로 파크골프 기록`.
   - 매장 공용 구글 계정을 권장합니다. 담당자가 바뀌어도 이어 쓸 수 있습니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. `Code.gs` 안의 내용을 모두 지우고, `apps-script/Code.gs` 전체를 붙여 넣은 뒤 저장합니다.
   - 첫 운영자 닉네임을 바꾸고 싶으면 위쪽의 `FIRST_OP_NICK = '운영자'`를 고칩니다.
4. 시간대를 맞춥니다.
   1. ⚙ **프로젝트 설정**에서 "appsscript.json 매니페스트 파일 표시"를 체크합니다.
   2. `appsscript.json` 내용을 `apps-script/appsscript.json`으로 바꿉니다. 시간대가 `Asia/Seoul`이어야 날짜가 하루씩 어긋나지 않습니다.
   3. 시트의 **파일 → 설정 → 시간대**도 서울로 맞춥니다.
5. 함수 목록에서 **`setup`**을 고르고 ▶ **실행**을 누릅니다.
   - 권한 확인 창에서 **고급 → (안전하지 않음)으로 이동 → 허용**을 누릅니다. 내가 만든 스크립트라 정상입니다.
   - 끝나면 **첫 운영자 닉네임과 처음 비밀번호**가 나옵니다. 실행 로그에도 나옵니다. **꼭 적어 두세요.** 다시 볼 수 없습니다.
   - 시트 7개(회원, 로그인기록, 코스, 기록, 공개설정, 설정, 이력)와 매일 새벽 자동 정리·백업 예약이 만들어집니다.
6. **배포 → 새 배포 → 유형: 웹 앱**을 고르고 아래처럼 설정한 뒤 **배포**를 누릅니다.
   - 실행: **나**
   - 액세스: **모든 사용자**
7. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 서버 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 하세요. 주소가 그대로 유지됩니다.

## B. 설정 파일 한 줄 고치기

`js/config.js`를 열고, 복사한 웹 앱 URL을 넣습니다.

```js
window.LZ_CONFIG = { API: 'https://script.google.com/macros/s/……/exec' };
```

## C. GitHub에 올리기

1. GitHub에서 **New repository**를 누르고, 이름(예: `lezuro-jade`)을 정해 **Public**으로 만듭니다.
2. **Add file → Upload files**에 압축을 푼 폴더 **안의 내용 전부**를 끌어다 놓습니다. 파일과 폴더를 함께 놓으면 됩니다.
   - PC의 크롬이나 엣지에서 해야 폴더째 올라갑니다.
   - 저장소 맨 위에 `index.html`과 `css`, `js`, `assets`, `icons` 폴더가 보여야 합니다.
3. **Settings → Pages**에서 Branch를 `main` / `(root)`로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/`가 열리면 끝입니다.

> 앱을 고쳐 다시 올릴 때는 `sw.js` 맨 위의 `VERSION` 숫자를 하나 올리세요. 회원 폰에 "새 버전이 있어요"가 뜹니다.

## D. 첫 로그인과 회원 초대

1. 앱 주소를 열고, A-5에서 받은 운영자 닉네임과 처음 비밀번호로 로그인합니다. 바로 나만의 4자리로 바꾸게 됩니다.
2. 아래 메뉴 **회원**에서 닉네임과 종류(고정회원, 기간회원, 운영자)를 고르고 **계정 만들기**를 누릅니다.
   - 처음 비밀번호는 자동으로 만들어지고, 이 화면에서만 보입니다.
3. **카카오톡·문자로 보내기**를 누르면 안내문이 그대로 전달됩니다. 안내문에는 닉네임이 미리 들어간 개인 링크가 있습니다.
4. 회원은 링크를 열고 처음 비밀번호를 누른 뒤, 나만의 비밀번호로 바꿉니다. 그다음 홈 화면 추가 안내가 이어집니다.

## 사용 규칙 요약

| 기능 | 운영자 | 고정회원 | 기간회원(기간 중) | 기간회원(기간 끝남) |
|---|---|---|---|---|
| 코스 등록 | ○ | ○ | – | – |
| 파·거리 고치기 | 모든 코스 | 내가 처음 등록한 코스 | – | – |
| 코스 이름 바꾸기·지우기 | ○ | – | – | – |
| 내 기록 쓰기 | ○ | ○ | ○ | – (읽기만) |
| 다른 회원 기록 보기·가져오기 | ○ | ○ | ○ | – |
| 회원 관리, 매장 이름·로고 | ○ | – | – | – |

- **기간이 끝난 회원**: 본인 기록만 읽을 수 있습니다. 그 회원의 기록은 다른 회원에게도 보이지 않습니다. 운영자가 고정회원으로 바꾸거나 기간을 늘리면 다시 보입니다.
- **코스**: 모두 18홀입니다. 전반은 1홀~9홀, 후반은 1홀 (10홀)~9홀 (18홀)로 표시합니다.
  - 이름은 띄어쓰기 없이 스크린에 나오는 이름 그대로 씁니다. 예: `목행충주파크골프CD`. 같은 이름은 다시 등록할 수 없습니다.
  - 거리는 소수점 첫째 자리까지 넣을 수 있습니다.
- **홀 기록**
  - 기준을 하나 고릅니다: 최초화면, 홀컵, 내가 정한 곳(이름 직접 입력).
  - 방향과 칸 수를 정합니다. 0칸이면 "그대로"입니다.
  - **타격감**: 17 = 50M이고, 1마다 5M씩 달라집니다. 16 = 45M, 18 = 55M이고 "17(50M) 정도"로 표시합니다. +/− 버튼으로 바꾸거나 숫자를 직접 입력할 수 있고, 범위는 8~40입니다.
  - **참고사항**: 20자까지 씁니다.
- **자동 저장**: 고치고 1.5초 뒤 저장합니다.
  - 저장 전에 나가려 하면 "저장하고 나가기 / 저장하지 않고 나가기 / 계속 고치기"를 묻습니다.
  - 인터넷이 끊기면 폰에 보관했다가 다시 연결되면 저장합니다.
- **코스 등록 중에 나갈 때**: "임시 저장하고 나가기 / 지우고 나가기 / 계속 작성하기"를 묻습니다. 임시 저장한 내용은 다음에 이어서 쓸 수 있습니다.
- **로그아웃**: 확인창이 뜹니다. 저장 안 된 기록이 있으면 먼저 저장을 시도하고, 실패하면 다시 묻습니다. 로그아웃해도 닉네임은 기억해서 다음엔 비밀번호만 누르면 됩니다.
- **로그인**: 폰마다 마지막에 쓴 닉네임을 그대로 보여 줍니다. 비밀번호는 5번 틀리면 10분 동안 쉬고, 잊었을 때는 운영자가 **비밀번호 다시 만들기**를 합니다.
- **화면 꺼짐 방지**: 홀 편집 화면을 보는 동안에는 휴대폰 화면이 꺼지지 않습니다. 다른 화면으로 가면 원래대로 돌아옵니다.
  - 전원 버튼을 누르거나, 전화가 오거나, 다른 앱으로 가면 꺼질 수 있습니다. 앱으로 돌아오면 다시 켜집니다.
  - 아주 오래된 폰이나 절전 모드에서는 안 될 수 있습니다. 그때는 화면에 안내가 나옵니다.

## 홈 화면에 추가 (앱처럼 쓰기)

- **안드로이드(크롬)**: 안내 화면의 **홈 화면에 추가** 버튼 한 번이면 됩니다. 버튼이 없으면 ⋮ → 홈 화면에 추가를 누릅니다.
- **삼성 인터넷**: ≡ → 현재 페이지 추가 → 홈 화면을 누릅니다.
- **아이폰(Safari만 가능)**: 공유 버튼 → 홈 화면에 추가 → 추가를 누릅니다.
  - 홈 화면 아이콘으로 처음 열 때는 비밀번호를 한 번 더 눌러야 할 수 있습니다.
- **카카오톡에서 링크를 연 경우**: 앱이 "기본 브라우저로 열기"를 안내합니다.

아이폰은 앱이 스스로 홈 화면에 추가할 수 없게 되어 있어서, 단계별 안내로 대신합니다.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| "서버 주소가 아직 없어요" | B단계 `js/config.js` 확인 |
| "서버 응답을 읽을 수 없어요" | 배포 액세스가 "모든 사용자"인지, URL이 `/exec`로 끝나는지 확인 |
| 불러오는 중에서 멈춤 | 6초 뒤 빠진 파일 목록이 나옵니다. `css`, `js`, `assets`, `icons` 폴더가 올라갔는지 확인 |
| 날짜가 하루 어긋남 | A-4 시간대 확인 |
| 모든 운영자가 비밀번호를 잊음 | Apps Script에서 `devResetOperatorPin` 실행 → 첫 운영자 비밀번호 새로 만들기 |
| 데이터를 되돌리고 싶음 | 매일 새벽 `bkYYMMDD_…` 숨김 백업 시트가 생깁니다(7일 보관). 시트 메뉴 **보기 → 숨겨진 시트**에서 찾을 수 있어요 |

## 보안 메모

- 비밀번호는 소금과 후추를 더해 암호화한 값만 저장합니다. 후추는 시트가 아닌 스크립트 속성에 보관합니다.
- 로그인 정보(60일 유지)도 원본 대신 암호화 값만 저장합니다.
- 모든 권한 검사는 서버에서 합니다. 화면에서 숨기는 것만으로 막지 않습니다.
- 구글 시트 자체는 회원과 공유하지 마세요. 운영자도 앱으로만 관리하면 됩니다.
