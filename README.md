# 파크골프 공략노트 (v3.1 · 통합 서버 · 직접 가입)

스크린 파크골프 회원이 코스(18홀)마다 홀별 공략(기준·방향·칸 수·타격감)을 기록하고, 같은 매장 회원의 공개 기록을 참고·비교하는 휴대폰 웹앱입니다.

- 화면: GitHub Pages
- 서버: 구글 앱스크립트 **하나** (모든 매장 공통)
- 저장소: 구글 시트 **하나**

| 모든 매장 공통 | 매장마다 따로 |
|---|---|
| 계정·닉네임·비밀번호, 이용권(한 번 결제로 모든 매장), 코스 목록(이름·파·거리), 신뢰도(합산), 요금·결제·좌석·로고 | **홀 기록**(매장마다 센서·파워가 달라서), 공지(매장 공지), 문의(매장 표시), 운영자 |

**v2.2를 쓰고 있다면 아래 "v2에서 v3로 올리기"만 하면 됩니다(약 15분). v3.1(직접 가입·친구 초대·공지 그림)도 같은 순서로 한 번에 올라갑니다.** 처음 설치는 A → B → C → D → E → F 순서입니다.

## v2에서 v3로 올리기 (양주점 서버를 통합 서버로)

지금 쓰는 **제이드 양주점 구글 시트와 서버가 그대로 통합 서버**가 됩니다. 주소(웹 앱 URL)도 바뀌지 않아서 회원은 로그인을 다시 하지 않아도 됩니다.

1. **양주점** 시트 → 확장 프로그램 → Apps Script에서 `Code.gs` 내용을 모두 지우고 새 `apps-script/Code.gs`를 붙여 넣고 저장합니다.
2. 함수 목록에서 **`setup`**을 골라 ▶ 실행합니다. (처음 실행이면 Drive 백업 권한을 한 번 묻습니다 → 허용)
   - 매장 2곳(제이드 양주점, 양주만송점)이 만들어지고, **기존 회원·기록·결제·신뢰도·문의는 모두 양주점 것**으로 옮겨집니다.
   - 회원마다 바뀌지 않는 **회원번호(uid)**가 붙습니다. 닉네임을 바꿔도 기록이 그대로 이어지는 이유입니다.
   - 시트 탭 **매장**, **공지**, **그림**이 새로 생깁니다. 회원 탭 뒤쪽에 **src·dev·ref·refPay** 칸이 늘어납니다(직접 가입·추천용).
   - **친구 초대 홍보 공지**(그림 + "친구에게 알리기"·"가입 화면 보기" 단추, 맨 위 고정, 앱을 열 때 한 번 팝업)가 올라가고, 자주 묻는 질문에 새 질문 3개가 더해집니다(관리자가 고친 질문은 그대로).
3. **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 누릅니다. (주소 그대로)
4. GitHub의 파일을 모두 새 파일로 바꿉니다. `js/config.js`는 이미 양주점 주소가 들어 있는 새 모양으로 되어 있습니다.
   ```js
   window.LZ_CONFIG = { API: 'https://script.google.com/macros/s/……/exec' };
   ```
   (예전 모양 `BRANCHES`를 그대로 둬도 `DEFAULT` 매장 주소로 동작합니다.)
5. 관리자·운영자는 다음 로그인 때 **비밀번호를 6자리로 바꾸게 됩니다.** (지금 4자리로 들어간 뒤 바로 바꿈. 로그인 화면 아래 "운영자·관리자(6자리)" 링크로 칸 수를 바꿀 수 있어요)
6. **만송점 서버는 지우셔도 됩니다.** 만송점 시트·Apps Script 배포를 삭제하세요. 예전 `?s=mansong` 링크는 통합 서버의 양주만송점으로 열립니다. 만송점 회원은 관리자가 회원 탭에서 **기본 매장: 양주만송점**으로 새로 만들어 주세요.
7. **카카오톡 미리보기 카드**: `index.html`에 내 주소(`https://jys2465.github.io/lezuro-jade-yangju/`)가 이미 들어가 있어요. 올린 뒤 [카카오 공유 디버거](https://developers.kakao.com/tool/debugger/sharing)에서 이 주소를 넣고 **캐시 초기화**를 한 번 눌러 주세요. 저장소 이름을 바꾸면 `index.html`의 `og:url`·`og:image` 두 줄도 바꿔야 해요.
8. 아이콘·이름이 "파크골프 공략노트"로 바뀝니다. 아이폰 홈 화면 아이콘은 지우고 Safari에서 다시 **홈 화면에 추가**해야 새 아이콘이 됩니다.

## A. 구글 시트와 서버 준비 (처음 설치)

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. 이름 예: `파크골프 공략노트`.
2. **확장 프로그램 → Apps Script**에서 `Code.gs`를 모두 지우고 `apps-script/Code.gs` 전체를 붙여 넣고 저장합니다.
   - 위쪽 `ADMIN_NICK = '관리자'`가 처음 관리자 닉네임, `SEED_BRANCHES`가 처음 만들 매장 목록입니다.
3. 시간대: ⚙ 프로젝트 설정 → "appsscript.json 매니페스트 파일 표시" 체크 → `appsscript.json`을 `apps-script/appsscript.json`으로 바꿉니다(`Asia/Seoul`). 시트의 **파일 → 설정 → 시간대**도 서울로.
4. **`setup`** ▶ 실행 → 권한 창에서 **고급 → (안전하지 않음)으로 이동 → 허용**.
   - 끝나면 **관리자 닉네임과 처음 비밀번호(6자리)**가 나옵니다. 꼭 적어 두세요.
   - 매일 새벽 정리·시트 안 백업(7일), **매주 Drive 백업(구글 드라이브 "공략노트 백업" 폴더, 8주 보관)** 예약이 만들어집니다.
5. **배포 → 새 배포 → 웹 앱**, 실행: **나**, 액세스: **모든 사용자** → 배포 → **웹 앱 URL** 복사.

> 서버 코드를 고친 뒤에는 **배포 관리 → ✏️ → 새 버전**으로 배포하세요. 주소가 유지됩니다.

## B. 설정 파일

`js/config.js`의 `API`에 웹 앱 URL 하나만 넣습니다. 매장은 앱 안에서 관리합니다.

## C. GitHub에 올리기

1. GitHub에서 **New repository** → 이름 정하고 **Public**.
2. **Add file → Upload files**에 압축을 푼 폴더 **안의 내용 전부**를 끌어다 놓습니다(PC 크롬·엣지). 맨 위에 `index.html`과 `css`, `js`, `assets`, `icons`, `vendor`가 보여야 합니다.
3. **Settings → Pages**에서 `main` / `(root)` → **Save**. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/`가 열립니다.

> 앱을 고쳐 다시 올릴 때는 `sw.js` 맨 위 `VERSION`을 올리세요. 회원 폰에 "새 버전이 있어요"가 뜹니다.

## D. 첫 로그인과 계정 만들기

1. 앱을 열고 로그인 화면 아래 **"운영자·관리자(6자리) 비밀번호로 들어가기"**를 누른 뒤, 관리자 닉네임과 처음 비밀번호로 로그인 → 나만의 6자리로 바꿉니다. 관리자는 **현황판**으로 시작합니다.
2. **회원** 탭에서 닉네임·종류(체험·월간·연간·운영자)·**기본 매장**을 고르고 **계정 만들기**.
3. **카카오톡·문자로 보내기**로 안내문을 보냅니다. 안내문 링크에 기본 매장이 들어 있습니다(`?s=mansong&u=닉네임`).

## E. 결제 설정 (관리자만)

**설정 → 요금 · QR · 계좌 · 좌석 · 문의 · 로고**. 모든 매장 공통입니다. 이용권은 **한 번 결제로 모든 매장**에서 씁니다.

| 항목 | 처음 값 |
|---|---|
| 월간회원 (30일) | 1,000원 |
| 연간회원 (365일) | 9,000원 |
| 계좌이체 | 카카오뱅크 3333-05-8835107, 예금주 표시 `주*수` |
| 카카오페이 QR | 받은 QR(금액 없음) 주소 |

### 카카오페이 QR 바꾸는 법

1. 카카오페이 앱 → **송금** → **QR로 송금받기**(또는 내 QR)에서 QR을 만듭니다. 원하면 금액을 넣어 월간·연간용을 따로 만듭니다.
2. QR 화면을 **캡처**합니다.
3. 관리자 설정의 **QR 사진에서 읽기**를 눌러 캡처를 고르면, 주소(`https://qr.kakaopay.com/…`)를 자동으로 읽어 칸에 넣습니다.
4. **열어서 시험하기**로 송금 화면이 열리는지 확인하고 **설정 저장**을 누릅니다.

### 결제 흐름 (닉네임 송금 → 관리자 확인)

1. 회원이 결제 화면에서 월간·연간을 고릅니다. 시작일~종료일이 미리 보입니다.
2. 카카오페이(버튼·QR) 또는 계좌이체로 보냅니다. 화면에 **송금 메시지(또는 받는 분 통장 표시)에 닉네임을 적어 달라**는 안내와 [닉네임 복사] 버튼이 있습니다.
3. 회원이 **송금했어요**를 누르면 "입금 확인 중"이 됩니다.
4. 관리자는 **설정 → 결제 확인 · 환불**에서 카카오페이 내역이나 통장의 이름·금액을 보고 **승인**합니다. 승인하는 순간 이용이 시작됩니다.

기간 규칙은 이렇습니다.

- **체험 중에 결제**하면 승인한 날부터 바로 시작합니다.
- **월간·연간 회원**은 종료 14일 전부터 다시 결제할 수 있고, 종료일 **다음 날부터 이어 붙입니다.**
- **기간이 끝난 뒤** 결제하면 승인한 날부터 시작합니다.

> 개인 계좌·개인 카카오페이로는 입금을 자동으로 확인할 수 없어서 관리자 확인 방식입니다. 예금주 실명 일부(`주*수`)가 송금 화면에 보이는 것은 은행·카카오 정책이라 막을 수 없습니다.

### 환불 규정

- 기본은 기간 끝까지 이용합니다.
- 결제 후 **7일 이내**이고 기록을 쓰지 않았으면 **전액** 환불합니다.
- 그 밖에는 **남은 날짜만큼 나눠서** 환불합니다(100원 미만 버림). 예: 연간 9,000원, 100일 사용 → 6,500원.
- 결제 확인 화면의 **환불 계산하기**가 금액을 계산해 줍니다. 처리하면 그 회원의 기간이 어제로 끝나고, 돈은 직접 돌려보냅니다.

## F. 동시 사용 좌석 정하기 (부하 시험)

구글 앱스크립트는 한 계정이 동시에 처리할 수 있는 양에 한도가 있습니다. 그래서 동시에 쓰는 사람이 좌석 수를 넘으면 **대기 화면("내 앞에 N명")**을 보여 주고, 자리가 나면 자동으로 들어가게 했습니다.

- **10분** 동안 화면을 전혀 만지지 않으면 좌석을 비웁니다. 화면을 쓰는 동안에는 자동으로 유지됩니다.
- 운영자·관리자는 기다리지 않습니다.
- 처음 값은 40석이고, 0은 제한 없음입니다.

좌석 수는 실제 서버로 재서 정하는 것이 가장 정확합니다.

1. 컴퓨터에 [Node.js](https://nodejs.org) 18 이상을 설치합니다.
2. 회원이 거의 없는 시간(예: 새벽)에 압축을 푼 폴더에서 실행합니다.
   ```
   node tools/loadtest.js "https://script.google.com/macros/s/……/exec" 관리자비밀번호6자리
   ```
3. 시험용 체험회원 80명(lt01~lt80)을 만들어 동시 10 → 20 → 40 → 80명으로 요청을 보낸 뒤 표를 보여 줍니다. 끝나면 시험용 회원과 기록을 모두 지웁니다.
4. **"느린 쪽 5%가 3초 이하이고 오류가 없는" 가장 큰 인원의 70%**를 추천 좌석 수로 알려 줍니다.
5. 관리자 설정에서 좌석 수를 바꾸거나, 끝에 `--apply`를 붙여 다시 실행하면 자동으로 저장됩니다.

> 회원이 화면을 "보는 동안"은 서버에 요청이 거의 없어서, 실제로는 좌석 수보다 훨씬 많은 사람이 앱을 켜 두어도 괜찮습니다.

## 체험 직접 가입 (로그인 화면)

- 로그인 화면 아래 **"처음이세요? 5일 무료 체험 시작하기"** → 가입 화면.
  1. **닉네임**: 스크린 파크골프에서 쓰는 닉네임(한글·영문·숫자 2~8자). 적는 동안 쓸 수 있는지 바로 알려 줍니다.
  2. **자주 가는 기본 매장**: 열려 있는 매장 중에서 고릅니다. QR·초대 링크로 들어오면 그 매장이 미리 골라져 있습니다.
  3. **비밀번호 4자리** 두 번(쉬운 번호는 안 됨).
  4. 확인 내용(체험 5일·1인 1회, 끝나면 내 기록 보기만, 기록 기본 공개, 받는 정보)에 체크 → **바로 체험회원으로 시작**(자동 승인).
- 가입하면 바로 로그인되고 **사용 방법 4장**(기준 → 좌측·우측과 칸 수 → 타격감 17 = 50M → 같은 매장 회원 기록)이 나옵니다. 설정 → **사용 방법 보기**로 다시 볼 수 있습니다.
- 주소 끝에 `&join=1`이 붙은 링크·QR로 열면 가입 화면이 바로 열립니다(예: `…/?s=mansong&join=1`).
- **운영자가 만들어 주는 방법도 그대로**입니다. 매장에서 직접 도와 드릴 때 쓰세요.
- **악용 막기**
  - 한 휴대폰에서 직접 가입은 **30일에 1번**입니다. 또 하려 하면 "이 휴대폰으로 최근에 ○○ 닉네임으로 가입했어요"라고 알려 주고 그 닉네임 로그인으로 안내합니다.
  - 서버 전체 **1시간 30건, 하루 100건**(관리자 설정에서 바꿈)이 넘으면 잠시 마감합니다.
  - 회원 관리에 **[직접 가입]·[NEW]·[같은 폰 N개 더]·[정리 대상]** 표시가 붙습니다. 필터에 **새 가입**, (관리자) **정리 대상**(직접 가입 체험이 끝나고 30일 넘게 안 들어온 계정)이 있습니다. 지우기는 관리자가 직접 합니다.
  - 운영자는 소속 매장 **체험회원을 이용 중지**할 수 있습니다(장난 가입 대응).
  - 관리자 설정 → **직접 체험 가입: 받기 / 멈추기**. 멈추면 로그인 화면의 가입 버튼이 사라집니다.
- **닉네임을 다른 분이 먼저 차지했을 때**: 회원이 문의하기 → **닉네임 확인 요청**을 남기면(관리자만 답변), 관리자가 회원 관리 → 관리 → **닉네임 정리**로 바꿔 줍니다. 정리된 예전 닉네임은 바로 다른 분이 쓸 수 있습니다.

## 친구에게 알리기 · 추천 보상

- 설정 → **🎁 친구에게 알리기**: 내 초대 링크(`?s=기본매장&join=1&r=내코드`), **카카오톡·문자로 보내기**, 링크 복사, **친구가 보는 가입 화면 미리 보기**, 초대한 친구 목록(가입일, 결제 전 / +7일 받음).
- 친구가 내 링크로 가입하면 친구는 5일 체험으로 바로 시작합니다.
- 그 친구가 **월간이든 연간이든 이용권을 처음 결제(관리자 승인)**하면 **나에게 7일**을 더 줍니다. 친구 한 명당 한 번입니다.
  - 내 이용권이 남아 있으면 끝나는 날 뒤에 7일을 붙이고, 이미 끝났으면 오늘부터 7일입니다(체험 중이면 체험이 7일 늘어남).
  - 그 결제를 **환불하면 보상 7일도 다시 뺍니다.** 같은 휴대폰끼리 추천은 인정하지 않습니다. 운영진은 보상 대상이 아닙니다.
  - 관리자 설정 → **추천 보상**에서 켜고 끄거나 일수(1~60일)를 바꿉니다. (홍보 그림 안의 "7일" 글자는 그림이라 바뀌지 않으니, 일수를 바꾸면 홍보 공지 그림도 바꿔 주세요.)
- **추천인은 어디서 보나요**
  - 친구(추천한 사람): 설정 → 친구에게 알리기의 초대 목록("결제 전" → "+7일 받음").
  - 초대 링크로 가입하는 사람: 가입 화면에 "🎁 ○○님의 초대로 가입해요".
  - 관리자: **결제 확인 화면** 카드에 "🎁 추천인 ○○님 · 승인하면 ○○님에게 +7일", 승인하면 "추천인 ○○님에게 +7일" 알림. 최근 처리 목록에도 "이 결제로 +7일 보상". **회원 관리**에는 "추천: ○○"(보상까지 끝나면 ✓).
  - 시트 **이력**에 "추천 보상"·"추천인 정함"이 남습니다.
- **링크 없이 가입한 분의 추천인 정하기 (관리자)**: "친구 소개로 왔어요"라고 하면 회원 관리 → 관리 → **추천인 정하기**에 추천한 회원의 닉네임을 넣습니다. **첫 결제 전까지만** 정하거나 바꿀 수 있고, 비우고 저장하면 지워집니다. 자기 자신, 서로 추천, 같은 휴대폰으로 가입한 계정끼리는 안 됩니다. 운영진을 추천인으로 정할 수는 있지만 보상은 없습니다.

## 홍보 도구

- **카카오톡 미리보기 카드**: 앱 주소를 카톡에 보내면 "파크골프 공략노트 · 5일 무료 체험" 제목과 그림(`assets/og-card.jpg`, 1200×630)이 카드로 나옵니다. (위 "v2에서 v3로 올리기" 7번 참고)
- **친구 초대 홍보 공지**: 처음부터 맨 위에 고정된 공지입니다. 그림(`assets/promo-invite.jpg`)과 **친구에게 알리기**·**가입 화면 보기** 단추가 있고, 회원이 앱을 열 때 한 번 팝업으로 보입니다. 고치거나 지우는 것은 다른 공지와 같습니다.
- **가입 QR 포스터** (운영자·관리자, 설정 → 알리기): 매장을 고르면 A4 포스터 그림(로고, "5일 무료 체험", 매장 이름, 가입 QR)이 만들어집니다. **그림 저장** 또는 **인쇄**. QR을 찍으면 그 매장으로 가입 화면이 바로 열립니다.

## 매장

- 매장은 **서버 안의 칸**입니다. 관리자 → 설정 → **매장 관리**에서 **새 매장 만들기**(이름 + 매장 코드), 이름 바꾸기, 닫기/다시 열기를 합니다.
  - 매장 코드: 영문 소문자로 시작하는 2~16자(예: `suyu`). **나중에 바꿀 수 없습니다.** 매장 주소는 앱 주소 끝에 `?s=suyu`.
  - 닫은 매장은 회원이 고를 수 없고, 기록은 지워지지 않습니다.
- 회원이 원하는 매장이 없으면 문의하기 → **매장 추가 요청**으로 남깁니다(관리자만 답변).
- **모든 화면 위쪽 띠에 "📍 지금 매장 ▾"**이 보입니다. 누르면 매장을 바꿉니다. 회원도 자유롭게 바꿀 수 있습니다.
- 로그인하면 **마지막에 쓴 매장**(처음에는 기본 매장)으로 열립니다. 초대 링크의 `?s=`가 있으면 그 매장으로 엽니다.
- **기본 매장**: 계정을 만든 매장입니다. 회원은 매장 고르기 화면에서 **30일에 한 번** 바꿀 수 있습니다. 운영자의 기본(소속) 매장은 관리자가 회원 탭에서 바꿉니다.
- **다른 매장에서 코스를 열면** 기본 매장의 내 기록을 **흐리게 "참고"**로 보여 줍니다. **○○점 내 기록 가져오기**(빈 홀만 / 모두 덮어쓰기 / 홀 하나)로 지금 매장 기록에 넣고 매장에 맞게 고치면 됩니다. 내 기록이라 신뢰도는 오르지 않습니다.
- 다른 회원 기록은 **지금 매장 것만** 보입니다.

## 닉네임

- **모든 매장에서 하나뿐**입니다(대소문자 구분 없음).
- 설정 → 내 계정 → 닉네임 **바꾸기**. **7일에 한 번**, 입금 확인 대기 중에는 못 바꿉니다. 처음 관리자 계정(`관리자`)은 바꿀 수 없습니다.
- 예전 닉네임은 **7일 동안 다른 사람이 쓸 수 없게** 지켜 둡니다. 예전 닉네임으로 로그인하면 "최근에 바뀌었어요. 새 닉네임으로 들어와 주세요"라고 안내합니다.
- 회원번호(uid)로 기록·이용권·신뢰도·문의가 그대로 이어집니다. 결제 기록에는 결제할 때의 닉네임도 함께 남습니다.

## 공지사항

- 관리자: **모든 매장** 또는 매장 하나에 올립니다. 운영자: 소속 매장에만.
- 설정 → **공지 쓰기 · 관리** → 새 공지: 제목(40자), 내용(2,000자, 굵게·크게·색), **게시 시작일·끝나는 날**, **맨 위 고정**, **앱을 열 때 팝업으로 한 번**.
- **그림 1장**: 사진 고르기 → 자동으로 줄여서(가로 1080) 올립니다. 시트 **그림** 탭에 나눠 저장되고, 공지를 지우면 그림도 지워집니다.

- 본문에 `https://…` 주소를 적으면 눌러서 열 수 있게 바뀝니다.
- 회원: 코스 화면 위 **"📢 새 공지"** 띠, 설정 탭 빨간 숫자, 설정 → **공지 보기**. 팝업 공지는 폰마다 한 번만 뜹니다(고치면 다시 한 번).

## 코스

- 모두 **18홀**입니다. 전반은 1홀~9홀, 후반은 1홀 (10홀)~9홀 (18홀)로 표시합니다.
- **등록은 두 단계**입니다.
  1. 이름과 **전반 9홀**(파·거리, 원하면 홀마다 내 기록)을 넣고 **전반 저장하고 후반으로**를 누릅니다.
  2. "전반 9홀 저장이 완료되었어요. 후반 9홀 등록으로 갈게요." 다음에 **후반 9홀**을 넣고 **등록하기**를 누릅니다.
  - 후반까지 마치기 전에는 **등록한 본인에게만** 보이고, 코스 목록에 "후반 9홀 입력 필요"로 표시됩니다.
- **이름은 한 칸에 띄어쓰기 없이** 스크린에 나오는 그대로 씁니다.
  - 끝의 **AB, CD, BC, EF** 같은 영문 조합이 다르면 다른 코스입니다. AB·CD가 있어도 BC는 새 코스로 등록됩니다.
  - 같은 이름은 등록할 수 없고, "그 코스에 내 기록을 넣으세요"라고 안내합니다.
  - 기존 이름을 줄였거나 한 글자 다르게 쓰면 고친 이름을 제안합니다. 예: `목행충주호파크골프AB`가 있을 때 `목행충주CD` → **"목행충주호파크골프CD"로 등록할까요?**
  - 숫자만 다른 이름(1구장·2구장)은 다른 코스로 봅니다.
  - 한글로 끝나는 비슷한 이름은 "같은 구장의 다른 조합이 맞나요?"라고 한 번 묻습니다.

## 신뢰도

다른 회원이 **내 기록을 가져다 쓰면** 내 신뢰도가 올라갑니다.

- 가져오기(빈 홀만 채우기, 모두 덮어쓰기, 홀 하나만 가져오기)를 하면 그 기록을 쓴 회원에게 **1점**이 올라갑니다.
- **한 회원이 한 코스에서는 몇 번을 가져가도 1점**입니다. 다시 가져가면 날짜만 가장 최근으로 바뀝니다. 다른 코스·다른 매장에서 가져가면 따로 1점입니다. 점수는 **모든 매장을 합친 하나**이고, 목록에는 어느 매장에서 가져갔는지 함께 나옵니다.
- 가져온 직후 **되돌리기**를 누르면 방금 생긴 1점은 빠집니다(30분 안). 실수로 누른 것까지 세지 않기 위해서입니다.
- 코스 목록과 설정 위쪽의 **"내 기록 신뢰도 N점"**을 누르면 **언제(가장 최근), 누가, 어느 코스**를 가져갔는지 최근 순으로 보입니다.
  - 회원은 자기 목록만 볼 수 있습니다.
  - 운영자·관리자는 회원 관리 → 관리 → **신뢰도 보기**로 모든 회원의 목록을 볼 수 있습니다.
- 코스 페이지의 **참고할 회원**은 신뢰도 높은 순으로 나오고, 처음에는 신뢰도가 가장 높은 회원이 골라져 있습니다. 같은 점수면 기록한 홀이 많은 순입니다. 회원 이름 옆에 **"신뢰도 N점"**이 보입니다.
- 기간이 끝난 회원은 가져오기를 할 수 없어서 점수도 올라가지 않습니다. 코스나 회원을 지우면 관련 점수도 함께 정리됩니다.
- 구글 시트의 **신뢰도** 탭에 쌓입니다(가져다 쓴 기록 주인, 가져간 회원, 코스, 처음, 최근). 예전 시트에 이 탭이 없으면 처음 쓸 때 저절로 만들어집니다.

## 문의하기 (자주 묻는 질문 + 1:1 문의)

**처음에는 "시험" 상태**라서 관리자·운영자와 **시험 회원으로 지정한 계정**에게만 보입니다. 실제 서버에서 충분히 써 본 뒤 모두에게 여세요.

### 켜는 순서
1. 관리자: **설정 → 요금 · QR · 계좌 · 좌석 · 문의 · 로고 → 문의하기 (시험 모드)**
2. **시험 회원 닉네임** 칸에 시험해 볼 회원 닉네임을 넣고(예: `우리집`, 여러 명은 쉼표로) **설정 저장**을 누릅니다.
3. 시험이 끝나면 **모두에게**를 누르고 저장합니다. 문제가 생기면 **끄기**로 바로 숨길 수 있습니다.

### 자주 묻는 질문(FAQ)
- 처음 11개(비밀번호, 송금 확인, 다른 매장 이용, 매장 추가, 타격감, 다른 회원 기록, 홈 화면 아이콘, 체험 시작, 닉네임 확인 요청, 친구 초대, 화면 꺼짐)가 들어 있습니다.

### 1:1 문의
- 회원: **설정 → 문의하기 → 내 문의 → 새 문의 남기기**에서 분류·제목(30자)·내용(500자)을 씁니다.

- 답변 뒤에 **이어서 묻기**를 하면 다시 "답변 필요"가 됩니다. 해결되면 **해결됐어요(문의 종료)**를 누릅니다.
- 운영자·관리자: 하단 **문의** 탭에 답해야 할 건수가 빨간 숫자로 보입니다. 문의에는 회원의 폰 종류·앱 버전이 함께 옵니다.

| 분류 | 답변 |
|---|---|
| 결제·이용권 | **관리자만** (운영자는 보기만). 그 회원의 입금 확인 대기 결제가 함께 보입니다 |

- **글자 꾸미기**: 글자를 고른 뒤 **굵게 · 크게 · 빨강 · 파랑 · 초록 · 보통**을 누릅니다. 사진·링크는 넣을 수 없고, 붙여 넣으면 글자만 들어갑니다. 서버가 위 꾸미기 말고는 모두 지워서 안전합니다.

- 답변 뒤 7일 동안 추가 질문이 없으면 자동으로 종료되고, 종료 1년 뒤 지워집니다. 회원을 삭제하면 그 회원의 문의도 함께 지워집니다.

## 코스 페이지

- **화면 꺼짐 방지**: 코스 표·홀 편집·비교 분석을 보는 동안에는 휴대폰 화면이 꺼지지 않습니다. 다른 화면으로 가면 원래대로 돌아옵니다.
  - 전원 버튼, 전화, 다른 앱으로 가면 꺼질 수 있습니다. 돌아오면 다시 켜집니다.
- **내 기록만 보기**: 체크하면 다른 회원 줄을 숨깁니다. 폰이 기억합니다.
- **○○님 기록 가져오기**(위쪽):
  - **빈 홀만 채우기**: 내가 아직 기록하지 않은 홀만 채웁니다.
  - **모두 덮어쓰기**: 그 회원이 기록한 홀은 모두 그 기록으로 바꿉니다.
  - 가져온 뒤 **되돌리기**로 돌아갈 수 있습니다.
- **비교 분석**: 고른 회원과 홀별로 비교합니다.
  - 위쪽에 같은 홀·다른 홀·한쪽만 기록한 홀 수를 보여 줍니다.
  - 같은 기준이면 "○○님이 좌측으로 2칸 더", "타격감 1 더 셈(+5M)"처럼 차이를 보여 줍니다.
  - 기준이 다르면 직접 비교하기 어렵다고 알려 줍니다.
  - 홀마다 **이 홀 ○○님 기록으로**, **내 기록 고치기** 버튼이 있습니다.

## 홀 기록

- **기준**을 하나 고릅니다: 최초화면, 홀컵, 내가 정한 곳(이름 직접 입력).
- **방향과 칸 수**: 0에서 시작해 **−** 를 누르면 좌측(−1, −2 …), **+** 를 누르면 우측(+1, +2 …)입니다. 좌측·우측 각각 **15칸까지**이고, 숫자 밑에 "좌측 2칸"처럼 글로도 보여 줍니다. 0이면 "그대로"입니다. 꾹 누르면 빠르게 바뀝니다.
  - 아래 **빠른 단추**(−10 −5 −3 0 +3 +5 +10)를 누르면 그 칸 수로 바로 바뀌고, 이어서 −/+ 로 다듬으면 됩니다.
- **누를 때 진동**: 비밀번호 키패드(로그인·비밀번호 정하기·가입), 칸 수·타격감 단추를 누를 때 짧게 떨립니다. 끝(±15칸, 타격감 8·40)에 닿거나 비밀번호가 틀리면 조금 다르게 떨립니다. 안드로이드는 진동, 아이폰은 iOS 18 이상에서 가벼운 누름 느낌이며 휴대폰 설정에 따라 느껴지지 않을 수 있습니다. 설정 → **누를 때 진동**에서 끌 수 있습니다.
- **타격감**
  - 17 = 50M이고, 1마다 5M씩 달라집니다. "17(50M) 정도"로 표시합니다.
  - **처음부터 17이 채워져 있고**, 손대지 않으면 17로 저장됩니다.
  - +/− 버튼이나 숫자 직접 입력(8~40)으로 바꿉니다.
- **참고사항**: 20자까지 씁니다.
- **자동 저장**: 고치고 1.5초 뒤 저장합니다.
  - 저장 전에 나가려 하면 "저장하고 나가기 / 저장하지 않고 나가기 / 계속 고치기"를 묻습니다.
  - 인터넷이 끊기면 폰에 보관했다가 다시 연결되거나 앱을 다시 열면 저장합니다.
- **코스 등록 중에 나갈 때**: "임시 저장하고 나가기 / 지우고 나가기 / 계속 작성하기"를 묻습니다.

## 화면

- 이름·로고·색: **파크골프 공략노트**(청록·주황, 과녁과 공이 날아가는 길 모양). 다른 회사 상표와 닮지 않게 새로 만든 로고입니다. 관리자 설정에서 로고(밝은 화면용·어두운 화면용)를 바꿀 수 있습니다.
- **밝게 / 어둡게**: 맨 위 해·달 단추, 또는 설정의 화면 모드(밝게·어둡게·자동). 어두운 화면에서는 어두운 화면용 로고가 나옵니다.
- **글씨 크기**: 보통 / 크게 / 아주 크게.
- **빠른 화면 이동**: 한 번 본 화면(코스·현황·회원·설정·문의·공지 등)은 기억해 두었다가 바로 보여 주고, 뒤에서 새 내용을 받아 바뀐 부분만 다시 그려요. 로그인하면 자주 쓰는 탭은 미리 받아 둬요. 글을 쓰는 중이거나 창이 떠 있을 때는 화면을 바꾸지 않고 끝난 뒤에 반영해요.
- **로그아웃**: 모든 화면 위쪽 오른쪽(해·달 단추 옆) 단추. 쓰던 글이 있으면 먼저 물어봐요.

## 홈 화면에 추가 (앱처럼 쓰기)

- **카카오톡에서 링크를 연 경우**: 앱이 "기본 브라우저로 열기"를 안내합니다.
